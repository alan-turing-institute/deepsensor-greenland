Project overview

giant-sp is a sensor-placement tool for GIANT, built on top of DeepSensor (ConvNP models) and PyTorch. It trains spatial-interpolation models on gridded climate reanalysis/RCM data plus in-situ station observations, then uses the trained model to run active-learning searches for new sensor placements.

GIANT helps us to answer the question of "where should we place new sensors to most improve our ability to predict the target variable?"

Pipeline

Data loading → DeepSensor model/training → scripts that drive training, inference, and sensor placement.

1. Data loading
Per-source data loaders normalize gridded data and build DeepSensor context/target task samplers.
2. Training
A ConvNP model is trained to interpolate the target variable from sparse context observations, validated against both gridded truth and held-out stations.
3. Placement
The trained model drives a greedy active-learning search to propose new sensor locations that most reduce predictive uncertainty.

Data sources

  • CARRA2 — reanalysis data, temperature (2t_abs) target.
  • HIRHAM5 — regional climate model data (NetCDF), snowmelt (snmel_abs) target.
  • HIRHAM5 (Zarr) — the same HIRHAM5 source, pre-processed into Zarr with an added rolling 10-year-average covariate.

Model details

Models are DeepSensor ConvNPs (convolutional conditional neural processes) — a set-convolution encoder maps sparse, irregularly located context observations onto a grid, a U-Net processes that grid, and a decoder reads off a predictive distribution at target locations.

Architecture (configurable per experiment)

  • unet_channels — number of channels per U-Net layer.
  • unet_kernels — convolution kernel size.
  • num_basis_functions — basis functions used by the decoder.
  • likelihood — predictive distribution, e.g. Gaussian or zero-inflated Bernoulli-Gamma for precipitation-like targets (mixture probability + gamma shape/scale).

Training

Adam/AdamW/SGD optimizer, reduce-on-plateau LR scheduling, early stopping on validation loss, and periodic validation against both the gridded truth and held-out station observations. Runs are tracked in Weights & Biases (metrics, prediction maps, calibration/PIT histograms).

Sensor placement acquisition functions

ContextDist
Favors locations far from existing context observations.
Stddev
Greedily picks the location with highest predictive uncertainty.
MeanMarginalEntropy
Picks locations that most reduce mean marginal predictive entropy.
OracleRMSE
Uses ground truth to pick the location that most reduces RMSE — an upper-bound reference, not a deployable strategy.

Placement runs load a trained model from a W&B run and search via DeepSensor's GreedyAlgorithm.
