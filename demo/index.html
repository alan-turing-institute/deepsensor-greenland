Project overview

Where should we invest in new sensors to improve our ability to monitor climate tipping points?

GIANT-sp is a tool to aid optimal sensor placement for monitoring climate tipping points.

  • Building on the principles of active learning, it uses DeepSensor (ConvNP models) and PyTorch.
  • It trains spatial-interpolation models on gridded climate reanalysis/RCM data plus in-situ station observations, then uses the trained model to run active-learning searches for new sensor placements.
  • This demo showcases the tool's capabilities and provides a dashboard for exploring the data, model, and sensor-placement results for surface melt.

Pipeline

Data loading → DeepSensor model/training → scripts that drive training, inference, and sensor placement.

1. Data loading
Per-source data loaders normalize gridded data and build DeepSensor context/target task samplers.
2. Training
A ConvNP model is trained to interpolate the target variable from sparse context observations, validated against both gridded truth and held-out stations.
3. Placement
The trained model drives a greedy active-learning search to propose new sensor locations that most reduce predictive uncertainty.
