Building on the principles of active learning, GIANT-sp trains probabilistic models, specifically Convolutional Conditional Neural Process (ConvCNP) models, available in the DeepSensor library.

Pipeline

1. Data loading
Per-source data loaders normalize input data and build data iterators readable for ConvNP models.
2. Training
A ConvCNP model is trained to interpolate the target variable from sparse context observations, validated against unseen ground truth.
3. Placement
The trained model drives a greedy active-learning search to propose new sensor locations that most reduce predictive uncertainty.
